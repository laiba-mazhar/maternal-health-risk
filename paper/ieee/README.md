# IEEE manuscript

`main.tex` is the IEEE journal-format version of the study, formatted with
`IEEEtran` in journal (two-column) mode. Target venue as written: **IEEE Journal
of Biomedical and Health Informatics** — change the `\markboth` running head if
you submit elsewhere.

Compiles to **9 pages**, 26 references, no undefined citations or cross-references.

## Build

```bash
latexmk -pdf main.tex
```

or, without latexmk:

```bash
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

On Overleaf, upload the folder and set the compiler to pdfLaTeX — `IEEEtran` is
already installed there. On MiKTeX the class is fetched automatically on first
build; on TeX Live install `texlive-publishers`.

For a double-spaced single-column review copy, swap the document class line:

```latex
\documentclass[journal,onecolumn,draftclsnofoot,12pt]{IEEEtran}
```

## Before you submit

1. **Fill in the affiliation.** The `\thanks` block contains
   `[Department]`, `[Institution]`, `[City]` placeholders. They are deliberately
   obvious rather than plausible — do not submit with an invented affiliation.
2. **Verify every reference.** `references.bib` contains real published works,
   but volume, issue, page and DOI fields were written from memory and have
   **not** been checked against publisher records. Confirm each field and each
   author list against the DOI.
3. **Re-run on the real dataset.** Every number in the manuscript comes from the
   synthetic stand-in, and the provenance footnote says so. Regenerate with
   `python scripts/download_data.py && python scripts/train.py --source real`,
   then update Tables III–VIII and re-read the prose. The
   Section VI-C conclusion is the one most likely to reverse.
4. **Add ORCID and funding** statements if the venue requires them.
5. **Consider author biographies** — IEEE journals usually expect a short
   biography paragraph and photo at the end.

## A note on Urdu

**pdfLaTeX cannot typeset Urdu script.** Do not paste Urdu glyphs into
`main.tex` — they will silently drop or produce garbage. The Urdu deliverable is
presented through Fig. 5 (an interface capture, where the Nastaliq is rendered
by the browser) and through English glosses in the prose.

If a reviewer asks for the Urdu inline, switch the whole document to XeLaTeX and
add:

```latex
\usepackage{polyglossia}
\setmainlanguage{english}
\setotherlanguage{urdu}
\newfontfamily\urdufont[Script=Arabic]{Noto Nastaliq Urdu}
```

then wrap Urdu in `\text{\urdufont ...}`. Note that IEEEtran plus RTL plus
Nastaliq line-height needs manual `\baselineskip` tuning inside table cells, so
budget time for it.

## Figures

The five figures used are copied into this directory so the folder is
self-contained for submission, which is what most journals require. They are
generated by the project — regenerate with:

```bash
python scripts/make_figures.py      # fig3–fig6
python scripts/make_screenshots.py  # band-high.png
```

then re-copy them here.

## Relationship to `../paper.md`

`../paper.md` is the long-form working manuscript (10 sections, more discursive).
`main.tex` is the condensed, venue-formatted version: the same findings and the
same numbers, restructured to IEEE section conventions and trimmed to journal
length. If you change a number, change it in both — or better, regenerate
`../generated_tables.md` and copy from there.
